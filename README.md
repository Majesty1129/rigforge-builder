# RIGFORGE Seat Decal Builder v11

- 36개 디자인 적용
- 제공된 제작 PDF(로고 폭 220mm, 간격 15mm)에서 측정한 실제 제작 비율 사용
- 고객 화면은 기존과 동일
- 계산식: 각 로고 높이 = 선택 폭 / 제작 비율, 총길이 = 로고 높이 합 + 간격 합
- 새 디자인 추가용 숨겨진 관리자: Ctrl + Shift + A

검증 조합
- 폭 230mm / 간격 25mm
- Fanatec, Logitech G, Forza Horizon, Pirelli, Brembo, F1
- 계산 결과 약 409.55mm (Illustrator 실측 409.536mm와 약 0.02mm 이내)

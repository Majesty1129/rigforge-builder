# RIGFORGE Seat Decal Builder v13.2

- 37개 투명 PNG 로고
- 제작 미리보기 로고 폭 통일
- 로고별 수량 선택(1~99장)
- 로고 폭 150~300mm 선택
- 기존 견적 저장 및 스마트스토어 주문 기능 유지


## v13.3
- 선택한 로고 폭에 따라 각 디자인의 실제 높이를 실시간 표시
- 수량이 2장 이상이면 해당 디자인의 로고 높이 합계 표시
- 견적 정보에 총 로고 높이와 간격 합계 표시


## v13.4
- 견적 이메일의 선택 디자인 목록에 디자인별 중복 수량 표시
- 이메일 예시: `PLAYSEAT × 2장 (220 × 31.2mm)`

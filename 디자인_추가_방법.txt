RIGFORGE Seat Decal Builder v10 디자인 추가 방법

1. GitHub Pages에서 index.html을 연 상태로 Ctrl + Shift + A를 누릅니다.
2. 관리자 창에 새 PNG 파일을 여러 장 끌어놓거나 선택합니다.
3. 자동 입력된 디자인 이름을 확인하고, 필요하면 카테고리와 태그를 입력합니다.
4. '통합 logos.json 다운로드'를 누릅니다.
5. GitHub 저장소의 logos 폴더에 새 PNG 파일들을 업로드합니다.
6. 다운로드한 logos.json으로 저장소의 기존 logos.json을 교체합니다.
7. GitHub Pages 반영 후 Builder를 새로고침합니다.

주의
- PNG는 투명 배경을 권장합니다.
- 파일명은 서로 중복되지 않아야 합니다.
- 관리자 도구는 GitHub를 직접 수정하지 않습니다.
- 새 PNG와 생성된 logos.json을 둘 다 업로드해야 합니다.
- ratio 값은 브라우저가 이미지 원본 크기에서 자동 계산합니다.

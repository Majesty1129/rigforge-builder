RIGFORGE Seat Decal Builder v14 - SVG Manager

구성
- index.html: 고객용 Seat Decal Builder
- logo_manager.html: SVG 로고 관리자
- logos.json: 현재 로고 목록
- logos/: SVG 로고 41개
- jszip.min.js: ZIP 생성 라이브러리

관리자 열기
1. GitHub Pages에서 logo_manager.html 주소를 직접 엽니다.
2. 또는 Builder에서 Ctrl + Shift + A를 누릅니다.

이름 변경
- 표시 이름을 바꾸면 ZIP 내보내기 시 파일명도 자동으로 바뀝니다.
- 예: 자산 44.svg / 이름 SIM RACING PIT -> sim-racing-pit.svg

2. ZIP 압축 해제
